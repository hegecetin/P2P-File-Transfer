# P2P File Transfer

A simple peer-to-peer file transfer application built with Python, Tkinter, and Magic Wormhole.

## Features

- Peer-to-peer file transfers
- Magic Wormhole transfer codes
- Tkinter graphical interface
- Designed for Windows 10 and Windows 11

## Requirements

- Python 3.11–3.14
- Windows 10 / Windows 11
- `magic-wormhole >= 0.23.0`

Python and dependency compatibility may vary by version.

## Usage

Run the application with Python:

```bash
python p2p_file_transfer.py
```
