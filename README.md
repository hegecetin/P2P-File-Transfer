📁 Easy File Transfer

A desktop application built with Python and Tkinter that makes transferring files and folders between Windows computers easier.

The goal is to send and receive files without dealing with complicated terminal commands. The application uses Magic Wormhole as its file transfer mechanism.

✨ Features

📤 Send files: Send selected files to another computer.

📂 Send folders: Transfer folders easily.

📥 Receive files and folders: Save incoming content to a selected location.

🔑 One-time transfer codes: Start a transfer using a code generated by the sender.

📋 Copy transfer codes: Copy transfer codes to the clipboard.

📊 Transfer status: View transfer status, progress, and speed when available.

🌍 Bilingual interface: Turkish and English language support.

⚙️ Settings: Manage the application language and preferences.

🧾 Activity log: Record transfer operations and results in versions that include the logging feature.

🖥️ Requirements

Windows 10 or Windows 11

Python 3

Internet connection

Magic Wormhole

🚀 Installation

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/REPOSITORY_NAME.git
cd REPOSITORY_NAME

Replace YOUR_USERNAME and REPOSITORY_NAME with your GitHub username and repository name.

2. Install the required package

python -m pip install --upgrade "magic-wormhole>=0.23.0"

3. Run the application

python main.py

Note: If your Python file has a different name, replace main.py with the actual filename, such as dosya_aktar.py or dosya_aktar_islem_gunlugu.py.

📤 How to Use

Open the application on the sender's computer.

Go to the Send File tab.

Select the file or folder you want to send.

Start the transfer and share the generated transfer code with the recipient.

Open the application on the recipient's computer.

Go to the Receive File tab, enter the transfer code, and select a destination folder.

Wait for the transfer to complete.

The computers do not need to be connected to the same local network. An internet connection is required, and successful connectivity may depend on network conditions.

🔐 Security and Privacy

Transfers use the security mechanisms provided by Magic Wormhole.

Share transfer codes only with the intended recipient.

Do not share transfer codes publicly.

Do not use transfer codes received from unknown sources.

Development note: Numeric six-digit PIN pairing, Supabase-based matchmaking, and direct WebRTC transfers should not be considered available features until their implementation is complete.

🧾 Activity Log

Versions that include activity logging are designed to record transfer operations and their results locally. The actual log location and contents depend on the version being used.

Logs can help with troubleshooting and reviewing previous operations. Check log files before sharing them, as they may contain sensitive information.
